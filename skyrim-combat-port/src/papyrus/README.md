# Papyrus-скрипты мода

**Статус: в сборку не входят.** Архив релиза содержит DLL, `Rules.txt` и анимацию; `.pex` в нём нет,
и ни один скрипт отсюда не компилировался в текущем процессе сборки.

| Файл | Что объявляет | Нужен ли |
|---|---|---|
| `TGCP_Native.psc` | объявления нативных функций плагина (`IsBlocking`, `IsBlockingWithShield`, `Tick`, `SetEnabled`, `GetStats`) | да: без него CK не скомпилирует скрипт, который их вызывает |
| `TGCP_PlayerBlockWatcher.psc` | наблюдатель блока игрока | нет: логика перенесена в DLL |
| `TGCP_AnimEventProbe.psc` | пробник animation events | нет: измерения сделаны, выводы в `docs/reference/animation-events.md` |
| `TGCP_WebSpiderAbility.psc`, `TGCP_PackLeapState.psc` | паутина и прыжок стаи | нет: вертикальный срез по паукам/волкам отменён |

## Что это значит на практике

`Tick` плагина вызывается **только** скриптом-владельцем в игре. Если `.pex` со скриптом в `Data\Scripts`
нет, `Tick` не вызывается никогда, и в логе не будет строк `diag:` и `block probe:` — при этом правила
на попаданиях продолжают работать, потому что они висят на событии движка, а не на `Tick`.
