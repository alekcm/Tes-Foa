# Плагин как исходник

Сюда кладётся собранный в Creation Kit (или xEdit) файл `TGCombatPort.esp`.

Почему в Git:

- `.esp` — это исходник записей: расы, стили боя, заклинания, NPC, квест и алиасы. Без него записи существуют
  только на одном компьютере и не восстанавливаются из репозитория.
- Файл наш, не игровой, обычно маленький (десятки–сотни КБ), поэтому его допустимо коммитить.

Правила:

- Не класть сюда `.pex`: они собираются из `src/papyrus/` командой `python tools\build.py`.
- Не класть сюда мастер-файлы игры и чужие моды.
- После сохранения плагина в CK скопировать его из `Data` игры в эту папку (или сразу сохранить сюда, если CK
  позволяет выбрать путь, а затем скопировать обратно в `Data` для теста в игре).
- Перед коммитом проверить зависимости:
  ```powershell
  python tools\inspect_plugin.py src\plugin\TGCombatPort.esp --strict
  ```
  Не должно быть мастер-файлов, кроме `Skyrim.esm`, `Update.esm`, `Dawnguard.esm`, `HearthFires.esm`,
  `Dragonborn.esm`.

Сборка с этим плагином:

```powershell
python tools\build.py --name TGCombatPort --version 0.1.0 --plugin src\plugin\TGCombatPort.esp
```

Минус хранения `.esp` в Git — бинарный diff: изменения записей нельзя осмысленно просмотреть в коммите.
Если это станет проблемой, записи можно перевести в текстовый вид через Spriggit, но это отдельное решение
и отдельная зависимость, а не задача первого прохода.
