# Плагин `.esp`

**Сейчас в репозитории `.esp` нет.** Файл `TGCombatPort.esp` собран в Creation Kit и лежит только
в папке игры (`Data\TGCombatPort.esp`) на машине пользователя. В архив релиза он тоже не входит:
архив содержит DLL, `Rules.txt` и анимацию.

Почему так: `.esp` — бинарник, изменения записей не читаются в коммите, а DLL работает и без него.

## Если нужно положить `.esp` в Git

1. Скопировать `Data\TGCombatPort.esp` в эту папку.
2. Проверить зависимости:

   ```cmd
   python tools\inspect_plugin.py src\plugin\TGCombatPort.esp --strict
   ```

   Мастер-файлы, кроме `Skyrim.esm`, `Update.esm`, `Dawnguard.esm`, `HearthFires.esm`,
   `Dragonborn.esm`, — не должно быть.

3. Закоммитить. Минус — бинарный diff; если это станет мешать, записи переводятся в текст
   через Spriggit (отдельная зависимость).

## Чего здесь быть не должно

- `.pex` — компилированные скрипты, место им в архиве мода, а не в исходниках.
- Мастер-файлы игры и чужие моды.
