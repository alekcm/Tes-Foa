## Сводка

- Design/research: частично готово — есть общий боевой дизайн и enemy moveset design для 42 архетипов.
- Признак блока игрока подтверждён в игре (22.11.2026): `TGCP_PlayerBlocking` = 1 по `blockStartOut`, = 0 по
  `blockStop`; в логе `player block start (blockStartOut)` / `player block stop (blockStop)`. Без SKSE.
- **Отклонено пользователем (22.11.2026):** «финт» на ванильном `Debug.SendAnimationEvent(target, "bashStart")`
  в `TGCP_PlayerBlockWatcher`. Пользователь выбрал путь **через SKSE**; код финта будет переписан нативно.
  Сейчас этот код в скрипте есть, но считается непринятым и подлежит замене — в игре его не проверять.
- **SKSE-часть работает:** `skyrim-combat-port/native/` — C++ плагин на CommonLibSSE-NG (xmake), собирается
  в GitHub Actions (workflow `native`), публикуется в Releases. **Проверено в игре 22.11.2026:**
  DLL загрузилась, лог `TGCombatPort.log` содержит `TGCombatPort native loaded, runtime 1.7.104.0`
  и `TGCP_Native.IsBlocking зарегистрирована`.
- **0.1.1 вызывала вылет игры (признано и исправлено).** Причина: перехват функции движка
  `Actor::GetAttackChance` (`write_branch`). По логам 22.11.2026 (`TGCombatPort-3.log`, `skse64-3.log`)
  плагин грузился, хук вставал (`hook installed: … at 0x7ff6f4442830`), а игра падала при загрузке сейва.
- **0.2.0 — механика без хуков:** патчинг кода убран полностью. Пока игрок держит блок, скрипт раз
  в 0.25 с зовёт `TGCP_Native.Tick()`; плагин на 1,5 с поднимает `meleeData.bashMult` в `CombatStyle`
  ближайшего враждебного щитоносца (≤240) и возвращает исходное значение, кулдаун 7 с на бандита.
  **Проверено в игре 22.11.2026:** вылета нет, `Tick` работает, окна открываются ровно раз в 7 с
  (`bash window opened: actor=Бандит style=0003CF5A bashMult 1.70 -> 10.00 dist=168`), но **щитом
  бандит не бил** — только оружием. Вывод: одного `bashMult` мало.
- **0.2.1:** поднимаются все контекстные множители `CombatStyle` (`bashMult`, `bashRecoilMult`,
  `bashAttackMult`, `bashPowerAttackMult`, `powerAttackBlockingMult`), окно 2,5 с, и на время окна
  плагин слушает animation events бандита — в лог пишется `bandit anim: bashStart|attackStart|…`.
  **Проверено в игре 22.11.2026 (0.2.1):** все пять множителей поднимались до 10.0, но AI
  **ни разу не выбрал баш** — в логе только `bandit anim: attackStop`, ни одного `bashStart`.
- **0.3.0 — правила изменены по решению пользователя 22.11.2026:** баш выбивает игрока из блока
  **только если он блокирует не щитом** (заказ баша отдаёт DLL: `NotifyAnimationGraph("bashStart")`,
  кулдаун 7 с); если игрок блокирует **щитом**, баша нет — щит пробивается силовой атакой булавы
  (`kOneHandMace`) или двуручного молота/топора (`kTwoHandAxe`) через `powerAttackBlockingMult = 10.0`
  на 2,5 с. Поправка записана в `docs/skyrim_enemy_combat_design_spec.md`. В игре **ещё не проверялось**.
- **0.4.0–0.6.2 (кратко):** заказ баша убран из `CombatStyle`, стал прямым
  `NotifyAnimationGraph("bashStart")` через DLL; найден и подтверждён логом факт: `bashStart`
  слушателям не рассылается, приходит только `bashStop`; проверены animation events всех рас
  (`TESRace::attackDataMap`). Вывод: animation event не создаёт попадания.
- **0.7.1–0.7.2:** триггер переведён на настоящее попадание `RE::TESHitEvent` (флаги
  `kHitBlocked`/`kPowerAttack`/`kBashAttack`), дистанция баша читается из `fCombatBashReach`
  (в игре пришло 128 — значение меняет другой мод), правка `CombatStyle` удалена.
  **Проверено в игре (`TGCombatPort-10.log`):** стаггер накладывался (пользователь подтвердил),
  но блок не снимался — `block probe … blocking=true staggered=true`; **AS-1 опровергнуто**.
- **0.8.0:** механика вынесена в данные — `Data\SKSE\Plugins\TGCombatPort\Rules.txt`
  (правила = секции с условиями и эффектами), DLL читает файл и печатает правила в лог.
- **0.9.0:** в правилах можно указать любую атаку: `attacker.race`, `hit.source`, `hit.projectile`,
  `attack.kind`; каждое попадание печатается строкой `hit: … race=… source=… projectile=…`.
  **Проверено в игре (`TGCombatPort-11.log`):** `rule fired … via=попадание`, флаги `09`
  (блок + силовой). Найдено: спелл-стаггер «Топот великана» сам бил игрока и давал «разрыв земли»;
  `blockStop` в стаггере отклоняется (`sent=false`) — **AS-10 опровергнуто**.
- **0.10.0:** стаггер ставится состоянием графа (`NotifyAnimationGraph("staggerStart")`, AS-14) —
  без урона, без визуальных эффектов; блок гасится повторно всё окно дезориентации (1,2 с);
  спелл остался запасным путём и требует одного эффекта и нулевой площади.
  **Проверено в игре: пользователь подтвердил «сейчас всё работает».**
- **Следующий слой (дизайн, не реализовано):** четыре состояния защиты — без блока / оружие / щит /
  вард (`GetActorValue(kWardPower)`), матрица «атака → что пробивает» для всех семейств врагов,
  колющие силовые атаки (урон сквозь блок без снятия), кровотечение, обезоруживание.
  Документ: [`docs/combat-block-matrix.md`](docs/combat-block-matrix.md).
- **0.11.0 (в игре ещё не проверялась):** условие `player.ward` (`GetActorValue(kWardPower) > 0`),
  эффект `chip` (урон сквозь блок через `DamageActorValue`), правила уколов кинжала/меча в `Rules.txt`.
  В каждой строке попадания печатается `вард=<число>`.
- **0.12.0 — анимация укола без правки бинарников.** Пользователь распаковал все анимации игры, и
  в них нашлись готовые уколы: `_1stperson\animations\1hm_attackstab.hkx` (первое лицо) и
  `animations\1hm_sneakattackpowerforward.hkx` (выпад в третьем лице). Они назначаются клипом
  `1hm_attackpowerfwd.hkx` через Dynamic Animation Replacer с условием `IsEquippedRightType(1) OR
  IsEquippedRightType(2)` (мечи и кинжалы; номера типов — из документации DAR в открытой
  реализации `noxsidereum/dargh`). Файлы и инструкция: [`native/assets/anim/`](native/assets/anim/README.md).
  Топор, булава и молот бьют по-прежнему. В игре **ещё не проверялось**.
- **Разбор модов парсером (22.11.2026):** написан `tools/esp_dump.py` — читает ESP/ESM/ESL
  (записи, группы, подзаписи, zlib), достаёт заклинания, эффекты, `GMST`, ключевые слова.
  Две находки:
  [`docs/reference/wildcat-analysis.md`](docs/reference/wildcat-analysis.md) — Wildcat действительно
  делает ранения по частям (голова/рука/корпус/нога/спина, 300 с, «рука болит при атаке» = стаггер 0.5)
  и переопределяет `GMST` (`fBlockMax 0.8`, `fBlockPowerAttackMult 0.5`…);
  [`docs/reference/apocalypse-analysis.md`](docs/reference/apocalypse-analysis.md) — в Apocalypse 9.45
  **404 заклинания**, из них **32 готовые NPC-версии** (20 Destruction, 12 Conjuration); там же —
  решение, кому что давать (маг, некромант, нежить, лич, природный дух, босс).
  Таблица «оружие → что пробивает → эффект»: [`docs/weapons-and-effects.md`](docs/weapons-and-effects.md).
  Выдача заклинаний врагам **не реализована** — нужен код и проверка в игре (три открытых вопроса перечислены в документе по Apocalypse).
