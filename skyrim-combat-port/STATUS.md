## Сводка

- Design/research: частично готово — есть общий боевой дизайн и enemy moveset design для 42 архетипов.
- Implementation: частично — четыре Papyrus-скрипта и черновик записей; ни один скрипт не компилировался настоящим компилятором, записей в плагине нет.
- Build: не выполнялась.
- In-game test: не выполнялся.
- Целевая редакция по сообщению пользователя: Skyrim SE со всеми официальными DLC (Dawnguard, Hearthfire, Dragonborn); состав Creation Club/AE-контента не подтверждён.
- Целевой runtime и магазин/платформа: неизвестны; см. `SETUP.md`. Запись этих сведений нужна для выбора совместимости, не для доступа к ПК пользователя.
- Исследовательская книга и coverage JSON восстановлены в `data/`; данные в них остаются справочными и не подтверждены тестом в игре.
- Предкодовая оценка spider/wolf/bandit записана в `docs/vertical_slice_feasibility.md`; базовая реализация — записи + Papyrus, конкретный plugin-проект ещё не создан.
- Контракт сборки записан в `BUILD.md`; добавлены `.env.example` и `tools/check_env.py` (сам скрипт проверен на синтетическом дереве каталогов, не на реальной установке Skyrim).
- Черновик записей для среза — `docs/vertical_slice_records.md`; записи не создавались, плагин не собирался.
- Упаковка подготовлена: `tools/package.py` проверяет состав и собирает `dist/<мод>-<версия>.zip`; проверен на тестовой папке, реального архива мода нет.
- Сборка одной командой: `tools/build.py` (Papyrus → stage → zip). Обвязка проверена на заглушке компилятора; с настоящим `PapyrusCompiler.exe` не запускалась.
- Исходники в `src/papyrus/`: `TGCP_AnimEventProbe` (пробник animation events), `TGCP_PlayerBlockWatcher` (признак блока игрока), `TGCP_WebSpiderAbility` (кулдаун и каст паутины), `TGCP_PackLeapState` (состояние «один leap на стаю», без принудительного запрета). Ни один не компилировался настоящим компилятором и не запускался в игре.
- Линт Papyrus (`tools/papyrus_lint.py`) проходит на всех исходниках; тесты инструментов — 27 штук, проходят (`python -m unittest discover -s tests`). Линт не заменяет компилятор.
- План тестов — `TESTING.md`; инструкция по первым записям в CK — `docs/ck_setup_guide.md`. Оба документа написаны, но ни один шаг не выполнялся.
- Используемые Papyrus-функции сверены с документацией (`docs/papyrus_verification.md`); `DoCombatSpellCast` не используется, так как для Skyrim не подтверждён.
- `tools/inspect_plugin.py` читает мастер-файлы и ESL-флаг плагина (проверен на синтетических заголовках); сборка предупреждает о не-ванильных мастер-файлах.
- `tools/check_docs.py` проверяет локальные ссылки в Markdown; им найдена и исправлена битая ссылка на книгу в `docs/tainted-grail-skyrim-combat-research.md`. CI-workflow `.github/workflows/tools-tests.yml` запускает тесты, линт Papyrus и проверку ссылок.
- SKSE и animation toolchain не подключены; базовый путь (записи + Papyrus) выбран, версии инструментов не зафиксированы — см. `DEPENDENCIES.md`.
- Решение пользователя (2026-11-21): база — плагин + Papyrus; SKSE разрешён, если конкретная механика без него не работает или работает заметно хуже. Условия: точный runtime до добавления DLL, запись версии в `DEPENDENCIES.md`, обновление требований на Nexus. Новые анимации — только после проверки ванильных. См. `docs/how_a_skyrim_mod_works.md`.
