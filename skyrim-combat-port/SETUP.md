Windows PowerShell для чтения версии (замени путь на путь к своему `SkyrimSE.exe`):

```powershell

  Select-Object FileVersion, ProductVersion
```

Работай только с тем удалённым доступом, который явно настроен и тебе нужен; не публикуй пароли, ключи и полный доступ к компьютеру.
