# Локальное окружение проекта — заполнить под реальную установку

Не коммить личные токены/учётные данные и не записывай абсолютные пути, если репозиторий публичный. Версии не угадывать. Указать `UNKNOWN` и получить значение из установленного файла игры, если пока неизвестно.

## Игра

- Edition: Skyrim Special Edition / Anniversary Edition (уточнить)
- Store/platform: Steam / GOG / другое (уточнить)
- Runtime/game version (например, `1.x.x.x`): `UNKNOWN — заполнить`
- Где прочитана версия (свойство `SkyrimSE.exe`, launcher, лог): `UNKNOWN — заполнить`
- Язык игры: `UNKNOWN — заполнить`
- DLC: `UNKNOWN — перечислить установленные`
- Creation Club/AE content: `UNKNOWN — перечислить, если используется`
- Можно ли откатить/заморозить автообновление для тестового профиля: `UNKNOWN`

Windows PowerShell для чтения версии (замени путь на путь к своему `SkyrimSE.exe`):

```powershell
(Get-Item 'D:\Games\Skyrim Special Edition\SkyrimSE.exe').VersionInfo |
  Select-Object FileVersion, ProductVersion
```

## Разработка и запуск

- Windows version / архитектура: `UNKNOWN`
- Creation Kit: `не установлен` / `установлен, версия/дата неизвестны` / `установлен, версия: ...` — выбрать фактический вариант. Если его нет, так и написать; ставить заранее не нужно. Агент должен определить по согласованному способу реализации, нужен ли CK.
- xEdit установлен? версия: `UNKNOWN`
- Mod manager: `UNKNOWN`
- Отдельный тестовый профиль и минимальный load order: `UNKNOWN`
- Путь установки игры хранить локально, не коммитить: `UNKNOWN`
- Где установлены Skyrim/CK: `на моём ПК` / `в той же среде, где работает агент` / `другое — указать`
- Может ли coding agent читать файлы проекта из GitHub/вложений: `UNKNOWN`
- Может ли coding agent запускать CK/компилятор именно в своей рабочей среде: `UNKNOWN`
- Может ли coding agent запустить игру именно в своей рабочей среде и загрузить тестовую сцену: `UNKNOWN`

> Важно: если Skyrim и CK стоят только на твоём компьютере, облачный чат не получает к ним доступ автоматически. GitHub даёт доступ к отправленным в репозиторий файлам, но не к установленным программам, локальным папкам, экранам и сохранениям. В таком случае агент готовит/меняет проектные файлы в репозитории, а ты скачиваешь их и запускаешь CK/игру локально; результаты, логи и ошибки возвращаешь в чат. Работай только с тем удалённым доступом, который явно настроен и тебе нужен; не публикуй пароли, ключи и полный доступ к компьютеру.

Заполнить перед первым in-game тестом:

- Порядок плагинов/модов или экспорт списка профиля: `UNKNOWN`
- Новая игра или сохранение для теста; где оно хранится: `UNKNOWN`
- Шаги загрузки тестовой сцены/встречи: `UNKNOWN`
- Проверка чистого профиля без мода и сравнение результата: `UNKNOWN`
- Как вернуть установку к исходному состоянию: `UNKNOWN`

> Не прикладывай пользовательское сохранение, если оно содержит личные данные/не предназначено для публикации. Если тестовое сохранение необходимо агенту, передавай его отдельно и явно укажи, что его можно использовать.
