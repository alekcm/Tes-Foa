# Как поставить нужного врага перед собой (для первого раза)

Консоль в Skyrim — это не чит-меню и не отдельная программа. Это строка команд поверх игры,
как в старых играх. Ничего устанавливать не нужно, всё уже в игре.

**Важно:** для проверки механики этого мода искать или спавнить никого не надо — она срабатывает
на любого бандита со щитом в любой обычной драке. Инструкция ниже — на случай, когда нужен
конкретный враг именно сейчас.

## Шаг 1. Открыть консоль

В игре (когда ты не в меню, не в диалоге, а просто стоишь в мире) нажми клавишу **`ё`** —
ту, что слева от `1`, с `~` на ней. На английской раскладке это `~`.

Признак, что получилось: игра замирает, сверху вниз белым по чёрному опускается «шторка»,
и внизу мигает курсор для ввода. Мышь при этом работает, но игра стоит.

Если не открывается:
- нажми ещё раз (иногда первое нажатие уходит в окно игры при переключении фокуса);
- проверь, что не открыт инвентарь/карта/меню — сначала `Tab`, потом `ё`;
- на ноутбуках без клавиши `ё` помогает `Shift + ~` или клавиша слева от `1`.

## Шаг 2. Найти врага по имени

Напечатай и нажми Enter:

```
help draugr 4
```

Внизу появится список строк, в каждой — ID из восьми знаков и название. Например:

```
0001BCC0  Draugr
```

`4` в конце — это фильтр «показать записи, которые можно поставить в мир». Если вместо
драугра нужен бандит, пиши `help bandit 4`; вместо имени можно часть имени.

## Шаг 3. Взять ID

Достаточно **кликнуть мышью по нужной строке** — её ID сам подставится в строку ввода,
печатать восемь знаков руками не обязательно.

## Шаг 4. Поставить врага

Дописать в конце ` 1` (количество) и нажать Enter:

```
player.placeatme 0001BCC0 1
```

Враг появится прямо перед тобой, уже враждебный. `placeatme` = «поставить рядом со мной».

## Шаг 5. Закрыть консоль

Нажми `ё` ещё раз. Игра продолжится.

## Шаг 6. Убрать лишнее (если надо)

Открой консоль, **кликни мышью по врагу** (он подсветится, и вверху появится его ID),
напечатай `disable` и Enter. Он исчезнет.

## Что не надо делать

- Не вводить `kill` на себе и не трогать незнакомые команды: часть из них ломает сохранение.
- Не сохраняться поверх основного сейва после экспериментов — лучше отдельный сейв.

## Если что-то пошло не так

Консоль ничего не пишет в ответ на `placeatme`, если всё сработало: враг просто появляется.
Если появилось красное сообщение — значит ID набран неверно (проверь, что это ровно восемь
знаков из списка `help`).
