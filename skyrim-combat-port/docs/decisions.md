# Принятые решения

Короткий журнал, чтобы новый чат или будущий я не пересматривал уже согласованное. Каждое решение — либо
подтверждено пользователем, либо явно помечено как рабочее предположение.

## ADR-001. Целевая игра: Skyrim Special Edition со всеми официальными DLC

- **Дата:** 2026-11-21
- **Статус:** принято пользователем.
- **Суть:** цель — Skyrim SE; «все дополнения» трактуются как Dawnguard, Hearthfire, Dragonborn.
- **Не подтверждено:** точный runtime/exe, магазин/платформа, язык игры, наличие Creation Club/AE-контента.
- **Следствие:** CC/AE-записи идут отдельным optional-патчем, а не обязательной частью.
- **Где записано:** `SETUP.md`, `README.md`, `STATUS.md`.

## ADR-002. База реализации: записи плагина + Papyrus; SKSE разрешён по необходимости

- **Дата:** 2026-11-21
- **Статус:** принято пользователем (вариант «можно SKSE, если понадобится»).
- **Суть:** сначала `.esp` и `.pex`. SKSE-плагин добавляется, только если конкретная механика без него не
  работает или работает заметно хуже. Тогда фиксируется точный runtime, версия SKSE и требования на Nexus.
- **Следствие:** требования к игроку на первом релизе — только игра и DLC; SKSE-зависимость не появляется
  без доказанной причины.
- **Где записано:** `DEPENDENCIES.md`, `docs/how_a_skyrim_mod_works.md`, `STATUS.md`.

## ADR-003. Игровые файлы и инструменты не попадают в Git

- **Дата:** 2026-08-… (исходное правило репозитория), подтверждено 2026-11-21.
- **Статус:** принято.
- **Суть:** `SkyrimSE.exe`, мастера, `Data/`, BSA/BA2, CK, xEdit, SKSE, менеджеры модов, сохранения и логи
  остаются на машине пользователя. В Git — исходники, конфигурация, версии и ссылки.
- **Следствие:** агент не получает доступ к чужому ПК; сборка и тесты выполняются локально.
- **Где записано:** `BUILD.md`, `.gitignore`, `AGENT_TASK.md`.

## ADR-004. Формат поставки: один zip в структуре Data

- **Дата:** 2026-11-21
- **Статус:** рабочее решение, проверяется первым релизом.
- **Суть:** архив собирается `tools/package.py` из `build/stage`; плагин лежит в корне архива, скрипты —
  в `Scripts/`. Установка через MO2/Vortex, без ручного копирования.
- **Следствие:** GitHub Releases и Nexus получают один и тот же файл; версия в имени файла.
- **Где записано:** `RELEASING.md`.

## ADR-005. Порядок работы: сначала вертикальный срез, потом остальной scope

- **Дата:** 2026-08-… (из handoff), подтверждено.
- **Статус:** принято.
- **Суть:** сначала паук, волк и бандит; проверяем механики и инструменты, затем переносим остальные архетипы.
  Срез не отменяет полный scope.
- **Следствие:** новые системы не добавляются, пока срез не проверен в игре.
- **Где записано:** `AGENT_TASK.md`, `docs/vertical_slice_feasibility.md`, `TESTING.md`.

## Открытые решения

| Вопрос | Почему не решён | Что нужно |
|---|---|---|
| Точный runtime игры | пользователь не сообщал | `python tools/check_env.py`, значение из `SkyrimSE.exe` |
| Нужен ли SKSE | зависит от результатов пробника animation events | скомпилировать и прогнать `TGCP_AnimEventProbe` |
| Нужны ли новые анимации | зависит от читаемости ванильных | тесты SP-01…SP-15, WF-01…WF-06, BD-01…BD-05 |
| Имя плагина для релиза | рабочее `TGCombatPort.esp` | подтвердить перед публикацией |
