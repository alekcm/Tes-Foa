# Как мы работаем вместе

Коротко: **собранный мод мне присылать не нужно.** Мне нужны исходники (они уже в Git) и обратная связь из игры:
ошибки компиляции и строки лога. Сборку делаешь ты, потому что только у тебя есть игра и Creation Kit.

## Кто что делает

| Я (агент) | Ты |
|---|---|
| пишу `.psc`, инструменты, документацию | один раз ставишь Creation Kit |
| проверяю код линтом и тестами | собираешь `.esp` в CK (по `docs/ck_setup_guide.md`) |
| готовлю команды сборки и упаковки | запускаешь сборку: `python tools\build.py ...` |
| разбираю твои ошибки и логи | ставишь zip в отдельный профиль и тестируешь |
| правлю исходники по результатам | присылаешь текст ошибок, `[TGCP]`-строки лога, итоги тестов |

Я не запускаю Skyrim и не открываю CK: в моей среде их нет. Поэтому «проверено в игре» может появиться только
после твоего запуска.

## Цикл работы

1. Я меняю исходники в репозитории и пушу.
2. Ты делаешь `git pull`.
3. Собираешь:
   ```powershell
   python tools\build.py --name TGCombatPort --version 0.1.0 --plugin src\plugin\TGCombatPort.esp
   ```
   Если плагина ещё нет — `--skip-package`, соберутся только скрипты.
4. Ставишь `dist\TGCombatPort-0.1.0.zip` в тестовый профиль, запускаешь игру, проходишь нужные тесты из `TESTING.md`.
5. Присылаешь мне результат. Я правлю и цикл повторяется.

## Что присылать

- Полный текст ошибки `PapyrusCompiler.exe` (не «не компилируется», а все строки).
- Строки `[TGCP]` из `Documents/My Games/Skyrim Special Edition/Logs/Script/Papyrus.0.log`.
- Результаты тестов: ID из `TESTING.md`, что ожидал, что увидел.
- Если игра падает — что делал перед падением и есть ли мод в списке плагинов.

## Что коммитить

- **Да:** `.psc`, документацию, инструменты, `src/plugin/TGCombatPort.esp` (это наш маленький файл-исходник записей).
- **Нет:** `.pex`, `build/`, `dist/`, игру, CK, менеджеры модов, сохранения, чужие моды. Всё это уже в `.gitignore`.

Плагин в Git полезен: если он существует только на твоём диске, записи нельзя восстановить из репозитория.
Минус — бинарный diff; если начнёт мешать, позже можно перейти на текстовый формат записей (Spriggit), но это
отдельное решение и отдельная зависимость.

## Что присылать НЕ нужно

- Архив мода `dist/*.zip` — он собирается из исходников одной командой.
- Скомпилированные `.pex` — я не смогу из них узнать больше, чем из исходников и лога.
- Игру, `SkyrimSE.exe`, `Data`, CK, SKSE — это чужие файлы, их нельзя класть в Git.
- Скриншоты вместо описания — можно, но текстом быстрее: что нажал, что увидел.

## Когда мод станет «скачиваемым»

Когда все тесты среза пройдены и архив ставится в чистый профиль без ручных действий. Тогда zip прикрепляется
к GitHub Release и загружается на Nexus (`RELEASING.md`). Это финал цикла, а не его начало.
