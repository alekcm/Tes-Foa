# Первый заход в Creation Kit: что создать для среза

**Статус:** пошаговая инструкция, ещё не проверенная на твоей установке. Названия вкладок и кнопок в CK
могут отличаться в зависимости от версии и языка; если пункт не совпадает — это не ошибка мода, напиши, и я
поправлю шаг.

Смысл: получить минимальный рабочий плагин, на котором можно проверить скрипты и записи, до того как делать
все 42 архетипа. Каждый шаг заканчивается проверкой, которую видно сразу.

## 0. Подготовка

1. Поставить Creation Kit из Steam (библиотека → инструменты → Skyrim Special Edition Creation Kit).
2. В Steam у игры должен быть включён язык, совпадающий с игрой; иначе CK может ругаться на строки.
3. Запустить CK, дождаться списка файлов. Отметить `Skyrim.esm`, `Update.esm`, `Dawnguard.esm`,
   `Hearthfire.esm`, `Dragonborn.esm`.
4. **Не** делать активным `Skyrim.esm`. Нажать OK, дождаться загрузки, затем `File → Save` и сохранить новый
   плагин как `TGCombatPort.esp`. Дальше все записи создаём в нём.
5. Проверка: плагин появился в `Data` игры, а игра запускается с ним без ошибок.

## 1. Глобальная переменная «игрок блокирует»

1. `Miscellaneous → Global` → новый объект.
2. EditorID: `TGCP_PlayerBlocking`, тип Short, значение 0.
3. Проверка: объект виден в списке, значение 0.

## 2. Квест и алиасы

1. `Character → Quest` → новый квест `TGCP_MainQuest`.
2. Поставить «Start Game Enabled». Приоритет оставить по умолчанию.
3. Вкладка Quest Aliases → новый алиас `PlayerAlias`:
   - тип: Specific Reference → `PlayerRef`;
   - скрипты: добавить `TGCP_PlayerBlockWatcher`, в свойство `PlayerBlocking` указать глобальную переменную из п. 1.
4. Для проверки событий добавить второй скрипт на тот же алиас: `TGCP_AnimEventProbe`.
5. Второй алиас `MainQuestAlias` (необязательный) — сюда позже повесим скрипт состояния стаи
   `TGCP_PackLeapState`.
6. Сохранить плагин.
7. Проверка: в игре с включённым модом в `Papyrus.0.log` появились строки `[TGCP] block watcher registered` и
   `[TGCP] probe: registered`. Если строк нет — скрипты не скомпилированы/не привязаны, дальше идти рано.

> Логи Papyrus включаются в `Skyrim.ini`: секция `[Papyrus]`, `bEnableLogging=1`. Файл:
> `Documents/My Games/Skyrim Special Edition/Logs/Script/Papyrus.0.log`.

## 3. Паутина большого паука: эффект замедления

1. `Magic → Magic Effect` → новый эффект `TGCP_WebSlowEffect`.
2. Archetype: Value Modifier. Actor Value: `Speed Mult`. Magnitude: отрицательная (начать с −40…−60).
   Duration: 1.5. Тип эффекта — detrimental, с восстановлением.
3. Флаги: без area of effect, без «detrimental» на союзников; визуальный эффект — ванильный, свой не делаем.
4. Проверка: эффект создан, значения сохранены. Проверять его отдельно от заклинания пока не нужно.

## 4. Снаряд паутины

1. `Magic → Projectile` → новый `TGCP_WebProjectile`.
2. Тип — missile. Скорость подобрать так, чтобы игрок успевал уйти (начать со значения ниже ванильного
   «быстрого» снаряда).
3. Модель: продублировать ванильный снаряд паутины и использовать его модель. Свои модели в первый проход
   не добавляем, игровые файлы в репозиторий не копируем.
4. Проверка: снаряд виден, летит по прямой, не огромный.

## 5. Заклинание паутины

1. `Magic → Spell` → новый `TGCP_WebSpell`.
2. Тип: Spell, casting: Fire and Forget, delivery: Missile, projectile — из п. 4.
3. Эффект — из п. 3. Урон 0, цель — противник.
4. Проверка: заклинание кастуется вручную (через консоль или временный тестовый NPC) и замедляет цель,
   не обездвиживая её.

## 6. Способность большого паука со скриптом

1. `Magic → Magic Effect` → новый `TGCP_WebSpiderAbilityEffect`: тип Ability, скрытый в UI, duration 0.
2. На него повесить скрипт `TGCP_WebSpiderAbility`.
3. В свойствах указать `WebSpell` из п. 5. `CooldownSeconds` = 8, `MaxRange` — по размеру арены (начать с 1200).
4. `Magic → Spell` → новый `TGCP_WebSpiderAbility`: тип Ability, внутри эффект из п. 1.
5. Выдать способность только **большому** пауку: в записи NPC/шаблоне добавить её в список способностей.
   Малым паукам не выдавать.
6. Проверка: большой паук кастует паутину сам, не чаще раза в 8 секунд; малые — нет.

## 7. Стили боя

1. `Combat → Combat Style` → дубликат подходящего ванильного стиля, переименовать в `TGCP_SpiderLargeStyle`.
2. Настроить дистанцию и агрессию; точные поля подбираются по ощущению, но менять только один параметр за раз.
3. Аналогично `TGCP_SpiderSmallStyle`, `TGCP_WolfPackStyle`, `TGCP_WolfLoneStyle`, `TGCP_BanditShieldStyle`.
4. Привязать стили к тестовым NPC (или к шаблонам), не меняя ванильные записи.
5. Проверка: подопытный NPC использует новый стиль, ванильные NPC с тем же шаблоном не изменились.

## 8. Быстрая проверка в игре

1. Найти удобную локацию: лучше сделать сохранение рядом с пауками/волками или использовать консоль
   `player.placeatme <FormID>` для подопытного NPC.
2. Включить бог-режим на время проверки поведения (`tgm`), чтобы смерть не мешала наблюдению.
3. Прогнать тесты из `TESTING.md` по одному и записать результат в `STATUS.md`.

## Чего в первый заход не делать

- Не менять ванильные расы, стили и NPC — только новые записи.
- Не добавлять новые анимации и behaviour-графы.
- Не собирать SKSE-плагин: сначала проверяем, что не получилось на Papyrus.
- Не переносить записи из других модов.

## Если CK падает или не сохраняет

1. Сохраняться после каждого блока записей, а не в конце.
2. Проверить, что плагин не помечен как активный `Skyrim.esm`.
3. Если CK не запускается — проверить, что игра и CK одной версии/языка.
4. Текст ошибки сохранить и прислать: по нему обычно видно, чего не хватает.
