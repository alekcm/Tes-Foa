# Оружие: что пробивает и какие эффекты даёт

Справочник по глаголам атаки. Полная матрица «атака × состояние защиты» —
[`combat-block-matrix.md`](combat-block-matrix.md); здесь — по оружию.

Состояния защиты: **S0** без блока, **S1** блок оружием/кулаками, **S2** блок щитом,
**S3** вард (Малый/Устойчивый/Великий Оберег).

Статус эффектов: **есть** — работает в плагине; **план** — спроектировано, кода нет.

## Одноручное

| Оружие | Лёгкая атака | Силовая атака | Пробивает | Эффект |
|---|---|---|---|---|
| **Кинжал** | `slash` — режет | **`thrust`** — укол | `chip` сквозь **S1 и S2** (10 ед.), сквозь **S3** (6 ед.) | урон мимо блока, блок **остаётся**, оглушения нет — **есть** |
| **Меч** | `slash` | **`thrust`** | `chip` сквозь **S1** (8 ед.); **S2 останавливает** | урон мимо блока оружием — **есть** |
| **Топор** | `slash` | `chop` — тяжёлый рубящий | S1 ломает, S2 держит | оглушение + кровотечение — стаггер **есть**, `bleed` **план** |
| **Булава** | `blunt` | `bluntHeavy` | S0, S1 ломает; S2 держит | оглушение (`unblock` + `stagger`) — **есть** |
| **Кулаки** | `blunt` слабый | без изменений | ничего | — |

## Двуручное

| Оружие | Лёгкая | Силовая | Пробивает | Эффект |
|---|---|---|---|---|
| **Двуручный меч** | `sweep` — широкий замах | `chop` | S1 ломает, S2 держит | оглушение — **есть** |
| **Двуручный топор** | `sweep` | `chop` | S1 ломает, S2 держит | оглушение + кровотечение (`bleed` — **план**) |
| **Двуручный молот** | `blunt` | `hammerHeavy` | **S0, S1, S2** | оглушение; обезоруживание (`disarm`) — **план** |

Порядок «кто кого ломает» — из твоей постановки: булава пробивает оружие, но не щит; молот
пробивает и щит; вард держит молот, но снимается антимагией.

## Стрельба и магия

| Источник | Против S1/S2 | Против S3 | Эффект |
|---|---|---|---|
| Лук, стрелы | блокируются | блокируются | урон; блок не снимает |
| Арбалет, болты | блокируются | блокируются | урон; болт бьёт сильнее стрелы |
| Особый болт (разрывной) | фильтр `hit.projectile` | — | по правилу: например `chip` или `unblock` |
| Заклинание школы | не блокируются вардом… **гасятся** вардом | вард гасит | урон школы |
| Антимагия (`kDispel`) | — | **снимает S3** | `dispelward` — **план** |
| Крик, дыхание дракона | проходят сквозь S1/S2 | **снимают S3** | оглушение — **есть**, снятие варда — **план** |

## У существ

| Атака | Пробивает | Эффект |
|---|---|---|
| Лапа, укус, бивни | S1 | оглушение при пробитии — **есть** |
| Слэм/топот (медведь, тролль, великан, центурион) | S1, S2 | оглушение — **есть** |
| Паутина, яд | — | урон/замедление |

## Реализованные эффекты (что писать в `do = …`)

| Эффект | Что делает | Проверено |
|---|---|---|
| `unblock` | снимает блок (`blockStop`) и повторяет всё окно дезориентации 1,2 с | 0.7.2/0.10.0, лог |
| `stagger` | ставит игроку состояние стаггера (`staggerStart`) — без урона и визуальных эффектов | AS-14 |
| `chip` | снимает N здоровья **сквозь блок**; блок остаётся | AS-16 |
| `bash` | заказывает NPC баш | 0.5.0, лог |

## Планируемые эффекты (нужен код)

| Эффект | Чем реализуется | Что даёт |
|---|---|---|
| `bleed` | урон по времени через `ActorValueOwner::DamageActorValue` | топор оставляет кровотечение |
| `disarm` | архетип `kDisarm = 9` (`EffectArchetypes.h`) | меч/молот выбивает оружие |
| `dispelward` | сброс `kWardPower`/применение ванильного `kDispel` | антимагия снимает вард |
| `wound` | `DamageActorValue` по навыкам (`kOneHanded`, `kBlock`) на время боя | «рука повреждена» |
| `part` | надо знать часть тела — только через Precision API | попадание в голову/руку/ногу |

## Числа, взятые из данных (не из головы)

| Число | Значение | Источник |
|---|---|---|
| предел снижения урона блоком | 80 % | `fBlockMax = 0.8` в `Wildcat - Combat of Skyrim.esp` |
| блок оружием | 40 % | `fBlockWeaponBase = 0.4` там же |
| силовая по блоку | урон ×0.5 (Wildcat) / ×0.66 (ваниль) | `fBlockPowerAttackMult` |
| стоимость баша / силового баша | 15 / 40 стамины | `fStaminaBashBase`, `fStaminaPowerBashBase` |
| длительность ранения | 300 с | спеллы `WCT_Injury_Spell_*` |
| «рука болит при атаке» | стаггер 0.5 | `WCT_Injury_Spell_Arm_ProcOnAttack` |
| дистанция баша | читается в рантайме (у тебя 128, у Wildcat 134) | `fCombatBashReach` |

Подробный разбор мода: [`reference/wildcat-analysis.md`](reference/wildcat-analysis.md).

## Как это записывается в правилах

```
[dagger-thrust-through-any-block]
trigger = hit
hit-flags = blocked, power
attacker.weapon = dagger
player.blocking = yes
do = chip
chip = 10
cooldown = 0

[bandit-mace-breaks-weapon-block]
trigger = hit, bash
hit-flags = blocked
attacker.weapon = mace
player.shield = no
do = unblock, stagger
```

Один и тот же враг может попасть под несколько правил — они не конфликтуют, у каждого свой кулдаун.
