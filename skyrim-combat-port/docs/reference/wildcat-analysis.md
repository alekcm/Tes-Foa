# Что реально делает Wildcat: разбор `Wildcat - Combat of Skyrim.esp`

Файл лежит в репозитории (`WildCat/`), разобран нашим парсером `tools/esp_dump.py`:

```cmd
python tools/esp_dump.py "WildCat\Wildcat - Combat of Skyrim.esp"
python tools/esp_dump.py "WildCat\Wildcat - Combat of Skyrim.esp" --type SPEL
```

Результат разбора: **554 записи** — 164 `CSTY` (боевые стили), 139 `GMST` (настройки игры),
65 `MGEF` (магические эффекты), 49 `GLOB` (глобальные переменные), 42 `MESG` (сообщения),
26 `SPEL` (заклинания), 16 `LSCR`, 10 `KYWD` (ключевые слова), 9 `STAT`, 9 `MOVT`, 6 `ARTO`,
4 `BOOK`, 2 `SOUN`, 2 `LIGH`, 2 `QUST`.

Дальше — только то, что вычитано из файла. Это **[A]** — источник сама запись мода.

## 1. Урон по частям тела: он есть, и части перечислены

Ключевые слова (`KYWD`):

| EditorID | Смысл |
|---|---|
| `WCT_Injury_Keyword_Head` | голова |
| `WCT_Injury_Keyword_Arm` | рука |
| `WCT_Injury_Keyword_Chest` | корпус |
| `WCT_Injury_Keyword_Leg` | нога |
| `WCT_Injury_Keyword_Spine` | позвоночник (спина) |
| `WCT_Injury_Keyword` | общий маркер ранения |

Плюс отдельные варианты для зверей: `WCT_Injury_Spell_Leg_Animal` («Hind Leg Injury» — задняя нога),
`WCT_Injury_Spell_Arm_Animal` («Front Leg Injury» — передняя). То есть у животных части тела
упрощены так же, как ты и предлагал.

## 2. Что делает ранение каждой части (числа из `SPEL`)

Все ранения длятся **300 секунд** (5 минут), накладываются спеллом «Injured».

| Часть | Эффекты (магнитуда / длительность) | Что это значит в бою |
|---|---|---|
| Голова | `Head Injury` 5 / 300; `Head Injury - Halt Magicka` 1000 / 300 | отключает восстановление магии |
| Корпус | `Chest Injury` 5 / 300; `Chest Injury - Halt Stamina` 1000 / 300 | отключает восстановление выносливости |
| Рука | `Arm Injury` 0 / 300; `Arm Injury - Impact` | удар по руке + «Pain» (`WCT_Injury_Spell_Arm_ProcOnAttack`) = `Stagger Self` 0.5 | при атаке раненой рукой игрока стаггерит |
| Нога | `Leg Injury` 0 / 300; `- Running`; `- Sprinting`; `- Impact` 50 / 5 | нельзя бегать и спринтовать, удар на 50 ед. |
| Спина | `Spine Injury` 0 / 300; `- Impact` 0 / 2 | короткий эффект при попадании |

Все ранения дополнительно накладывают `Bleed Effect Shader` — визуальный эффект крови.

## 3. Стаггер: какие магнитуды мод считает рабочими

| Заклинание | Эффект | Магнитуда | Длительность |
|---|---|---|---|
| `WCT_Stagger_Spell_Self_020` | `Stagger Self` | 0.2 | 1 с |
| `WCT_Stagger_Spell_Self_050` | `Stagger Self` | 0.5 | 1 с |
| `WCT_InjuriousBlow_Spell` | `Stagger Self` 0.25 + `Injurious Blow` | 0.25 | — |
| `WCT_Stagger_Spell_Self_...` в проках руки | `Stagger Self` | 0.5 | — |

Мы используем `staggerStart` (состояние графа) и магнитуду не задаём — но полезно знать, что
0.2–0.5 мод считает достаточным, а 1.0 у нас не «перебор», а верх шкалы.

## 4. Блок и стамина: значения, которые мод переопределяет (`GMST`)

| Настройка | Значение Wildcat | Смысл |
|---|---|---|
| `fBlockMax` | 0.8 | максимум, до которого блок снижает урон (80 %) |
| `fBlockWeaponBase` | 0.4 | блок оружием даёт 40 % |
| `fBlockWeaponScaling` | 0.25 | вклад навыка блока при блоке оружием |
| `fBlockPowerAttackMult` | 0.5 | силовая атака по блоку: урон ×0.5 (в ванили 0.66) |
| `fStaminaBashBase` | 15 | стоимость баша |
| `fStaminaPowerBashBase` | 40 | стоимость силового баша |
| `fStaminaBlockDmgMult` | 0.3 | доля урона, уходящая в стамину при блоке |
| `fStaggerMaxDuration` | 2.5 | предел длительности стаггера |
| `fStagger1WeapMult` | 0.25 | стаггер одноручным |
| `fStagger2WeapMult` | 0.75 | стаггер двуручным |
| `fStaggerShieldMult` | 0.75 | стаггер щитом |
| `fCombatBashReach` | 134 | дистанция баша у этого мода |
| `fCombatBashChanceMin/Max` | 0.2 / 0.4 | шанс, что AI выберет баш |

Важно: у тебя в логе плагина приходило `fCombatBashReach = 128`, то есть **побеждает не Wildcat**
(134) — значит дистанцию переопределяет ещё один мод. Это ещё одна причина читать значение
в рантайме, а не зашивать число.

## 5. Глобальные переключатели (`GLOB`), которые нас касаются

| EditorID | Значение по умолчанию | Смысл |
|---|---|---|
| `WCT_Modifier_Global_DisableDirectionalDamage` | 0 | направленный урон включён |
| `WCT_Modifier_Global_DisableDynamicDamage` | 0 | динамический урон включён |
| `WCT_Ability_Global_AttacksCostStamina_1H` | 2.5 | стоимость атаки одноручным |
| `WCT_Ability_Global_AttacksCostStamina_2H` | 5.0 | стоимость атаки двуручным |

## 6. Чего в `.esp` НЕТ — и где это искать

- **Как именно определяется часть тела.** В `esp` только ключевые слова, эффекты и сообщения.
  Логика лежит в Papyrus-скриптах внутри `Wildcat - Combat of Skyrim.bsa` (скомпилированные `.pex`).
  Их можно прочитать (строки в `.pex` не шифруются), но это отдельный разбор архива BSA.
- **Порогов урона** в `esp` нет: они либо в скриптах, либо в `GLOB`-ах, которые мод меняет в игре
  через меню настройки (`WCT_ConfigurationPower_Spell`).

Поэтому наши числа для травм берём из того, что видно: длительность 300 с, отключение регенерации
магии/стамины, «рука болит при атаке» = стаггер 0.5, «нога» = запрет бега и спринта.

## 7. Что из этого следует для нас

| Механика | Можно ли повторить | Чем |
|---|---|---|
| Ранение части тела | да, если часть известна | нужен источник части: Precision API (`PrecisionHitData.hitRigidBody->name`) — см. `docs/combat-block-matrix.md`, раздел 6 |
| «Рука болит» = стаггер при атаке | да | `staggerStart` по флагу «ранен» (наша актёрская пометка) |
| «Нога» = запрет бега | да | урон/снижение актёрских величин скорости (`SpeedMult`) |
| «Голова» = нет магии, «корпус» = нет стамины | да | `DamageActorValue(kMagickaRate/kStaminaRate)` на время |
| Кровотечение | да | эффект `bleed` (урон по времени через `DamageActorValue`) |
| Части тела без Precision | нет | в `TESHitEvent` части нет, только флаги |
