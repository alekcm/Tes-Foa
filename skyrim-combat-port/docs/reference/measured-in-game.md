## 0.6.2 — лог `TGCombatPort-9.log` (71 строка, 16:06:32–16:07:30)

Главный измерительный лог проекта. Что в нём:

| Строка | Факт |
|---|---|
| `TGCombatPort v0-6-2-0` | версия DLL в игре действительно 0.6.2 |
| `stagger spell: …` × 12, `stagger: выбран спелл Warmaster Knockdown (00106254) из 129 кандидатов` | поиск спелла работает, кандидатов 129 |
| `bash ordered: … event=bashStart sent=true` × 5 | заказ баша проходит |
| `bandit anim: bashStop` × 5 (через 0,12–0,34 с) | анимация начинается и обрывается |
| `bandit anim: bashStart` — **0 раз** | движок не рассылает `bashStart` слушателям |
| `stagger applied` — **0 раз** | наш эффект не вызывался ни разу: триггер стоял на `bashStart` |
| `power window opened` — **0 раз** | правило «силовая по блоку щитом» не включалось: игрок блокировал мечом |
| `diag: blocking=true withShield=false hostiles=1` | игрок всё время блокировал без щита, рядом один бандит со щитом и стальной булавой |

Выводы, на которых стоит 0.7.0:

1. Триггер механики не может быть на `bashStart` — событие не приходит. Надёжный сигнал — `bashStop`. **[A]**
2. Заказ баша анимацией **не создаёт попадания** (это idle-анимация), поэтому «бьёт и не попадает» —
   не баг конкретной версии, а свойство механизма. **[A]**
3. Ванильная силовая атака блок не ломает; ломать должен наш эффект. **[A]** (плюс **[B]** по UESP)
