# Реестр допущений (Assumptions Register)

Правило проекта: **всё, что не подтверждено источником [A]/[B], живёт здесь с номером.**
В коде такие места помечены комментарием `AS-n`. Проверка автоматическая:
`python tools/verify_audit.py` падает, если в коде есть `AS-n`, которого нет в этой таблице,
или если у записи нет строки «Проверяется».

Статусы: `открыто` — не проверено в игре; `подтверждено` — есть лог; `опровергнуто` — есть лог.

| ID | Допущение | Почему принято | Проверяется (строка лога) | Статус |
|---|---|---|---|---|
| AS-1 | Ванильный спелл с архетипом Stagger, скастованный NPC на игрока через `CastSpellImmediate`, **снимает блок у игрока** | в движке нет сеттера блока; стаггер по UESP прерывает текущее действие | `block probe: … blocking=false` — подтверждено; `blocking=true` — опровергнуто | открыто |
| AS-2 | `magnitude = 1.0` на таком спелле даёт заметный стаггер (не «ничего» и не рагдолл) | шкала magnitude 0..1 по CK Wiki; для игрока «стоячие» значения по отзывам не работают | `block probe: … staggered=true` + визуально | открыто |
| AS-3 | Событие `bashStop` — это конец замаха баша, подходящий момент для эффекта | `bashStart` слушателям не приходит (лог 0.6.2), `bashStop` приходит | интервал `bash ordered` → `bash finished` = 0,1–0,6 с | открыто |
| AS-4 | `CastSpellImmediate` на `kInstant`-кастере NPC не требует анимации каста и не тормозит бой | сигнатура `MagicCaster::CastSpellImmediate` (VTABLE 01), имя параметра `a_noHitEffectArt` | наличие `stagger cast:` без вылета и без пауз в бою | открыто |
| AS-5 | События `attackPowerStart*` / `bashPowerStart` доходят до `BSAnimationGraphEvent`-слушателей | на них подписан 0.7.0; для `bashStart` это оказалось неверно | строка `power attack start: … event=attackPowerStart…` | открыто |
| AS-6 | `ActorState::IsWeaponDrawn()` = «оружие и щит в руках»; при `false` баш проигрывается кулаком | метод есть в заголовках; семантика по имени | `bash finished: … shield=true` при вынутом оружии | открыто |
| AS-7 | `Actor::IsStaggering()` возвращает `true` именно в момент стаггера у игрока | метод есть в заголовках; поведение не документировано | `block probe: … staggered=true` | открыто |
| AS-8 | Конец заказа баша (`bashStop` при `dist ≤ 140`) визуально совпадает с моментом «щит достал игрока» | геометрия анимации не документирована | визуально + `bash finished: … dist=…` | открыто |

| блок против силовой атаки работает на 66 % и не исчезает | `fBlockPowerAttackMult = 0.66`, UESP Skyrim:Block **[B]** |
