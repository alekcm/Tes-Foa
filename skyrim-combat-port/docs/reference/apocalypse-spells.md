# Apocalypse 9.45.0: что делает каждое заклинание (справочник)

Источник — официальное описание мода версии **9.45.0** (страница мода, см. «Источники» внизу).
Версия совпадает с `.esp`, который лежит в репозитории (`Apocalypse v945-16225-9-45.zip`), поэтому
названия и числа относятся к тому же файлу. Метка **[C]**: это описание автора мода, а не наш лог;
конкретные числа в игре могут отличаться из-за перков, сложности и других модов.

Сверка с файлом: **404** записи `SPEL` в `.esp` против 155 «заклинаний» в описании. Разница не
ошибка: в `esp` отдельными записями лежат версии для игрока (`_PC`), версии для NPC (`_Spell_NPC`),
проки, хзарды и служебные эффекты. Поэтому, когда ниже написано «у NPC своя версия», речь именно
про эти `_Spell_NPC` записи.

Пометка «только свиток» — заклинание существует только как свиток (`SCRL`), в `SPEL` его нет:
проверено парсером (`Mind Fog`, `Dust to Dust`, `Gravisphere`, `Oblivion Unbound` не находятся
командой `--type SPEL`).
