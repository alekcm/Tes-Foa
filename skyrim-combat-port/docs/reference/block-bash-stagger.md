# Блок, баш, стаггер, силовые атаки

## 1. Чем можно блокировать

- Блок работает **со щитом, факелом, одноручным или двуручным оружием**; кулаками блокировать нельзя. **[B]**
  UESP: «Block allows you to reduce damage from melee and ranged combat, using a shield, a torch,
  a one-handed weapon, or a two-handed weapon» — <https://en.uesp.net/wiki/Skyrim:Block>
- В коде игры это проверяется через экипированный объект в левой руке: щит — `TESObjectARMO` с флагом щита.
  У нас: `HasShield()` в `native/src/main.cpp`, проверено логом (`diag: … shield=True/False`). **[A]**

## 2. Силовая атака и блок

- UESP пишет: «Power attacks can be used to deal extra damage or **break through** an opponent's block». **[B]**
  <https://en.uesp.net/wiki/Skyrim:Combat>
- **Что это значит на самом деле:** блок при силовой атаке работает хуже, но **не исчезает**.
  В формуле урона блока появляется множитель `fBlockPowerAttackMult = 0.66`: заблокированный урон
  умножается на 0,66, блок продолжает действовать. **[B]** — там же выведены формулы, например
  Hide Shield против силовой атаки блокирует 51,98 % вместо 78,75 %.
- **Вывод:** «пробить блок» силовой атакой = нанести больше урона, а не сбить блок.
  Отдельной механики «силовая атака выбивает из блока» в ванили нет. **[B]**

## 3. Баш

- Баш — это атака при блоке (нажать атаку, не отпуская блок). Работает щитом, оружием, факелом. **[B]**
  UESP: «Tapping the attack button while blocking will bash your opponent with a shield or weapon».
- Эффект баша по UESP: «**carries a chance of staggering** an opponent and of **interrupting an opponent's
  power attack**». **[B]** То есть: шанс стаггера и прерывание силовой атаки. **Гарантированного сбивания
  блока нет** — ни в описании, ни в механике. <https://en.uesp.net/wiki/Skyrim:Block#Bashing>
- Множители стаггера по типам атак (UESP, таблица помечена самой вики как «verification needed»): **[C]**
  | Атака | Урон | Стаггер | Выносливость |
  |---|---|---|---|
  | Обычная атака | ×2 | ×1 | ×1 |
  | Баш | ×0.5 | ×0.5 | ×1 |
  | Силовой баш | ×1.5 | ×1.5 | ×1 |
- Баш требует **вынутого** оружия/щита: пока оружие убрано, тот же animation event проигрывает удар кулаком. **[C]**
  (в 0.6.2 добавлена проверка `ActorState::IsWeaponDrawn()`, см. `measured-in-game.md`)

## 4. Стаггер — единственный механизм, который действительно «выбивает»

- UESP: «**Staggering interrupts whatever action was being taken by the target** and temporarily stuns them,
  preventing any further attacks until they have recovered». **[B]**
  <https://en.uesp.net/wiki/Skyrim:Combat#Staggering>
  → если актёр в этот момент блокировал, блок прерывается вместе с действием. Это и есть «выбить из блока».
- Разница игрок/NPC: у NPC стаггер ещё и останавливает движение; у игрока по UESP движение сохраняется
  (сама вики помечает это как «verification needed»). **[C]**
- Blade and Blunt (крупный боевой оверхол) описывает то же: для **игрока** рост magnitude стаггера
  в ванили даёт в основном тряску камеры, а полноценная блокировка управления включается только модами. **[C]**
  <https://www.nexusmods.com/skyrimspecialedition/mods/34549>
  → отсюда риск: на NPC стаггер работает предсказуемо, на игроке — надо измерять (этим и занимается 0.7.0).
- Чем вызывается стаггер в ванили: силовые атаки (шанс), некоторые крики (гарантированно),
  перки Impact/Power Shot/Power Bash. **[B]**

## 5. Чего в движке НЕТ (проверено по заголовкам)

- Нет функции «застаггерить актёра на N миллисекунд»: в `RE::Actor` есть только чтение —
  `IsStaggering()`, `ActorState::IsStaggered()`. Сеттеров нет вообще. **[A]**
  Подробнее — [`commonlib-api.md`](commonlib-api.md).
- Нет функции «заставить NPC ударить щитом». Есть только `NotifyAnimationGraph(...)`, который
  проигрывает анимацию, но **не создаёт атаку** (нет хитбокса, нет attack data, нет попадания). **[A]**
  См. [`animation-events.md`](animation-events.md).
