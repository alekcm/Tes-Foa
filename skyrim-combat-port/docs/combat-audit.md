# Аудит боёвки: решения, рычаги, что отклонено

Регистр решений и причин. Сами таблицы «что чем пробивается» живут в одном месте —
[`combat-block-matrix.md`](combat-block-matrix.md), чтобы не было двух правд.
Заклинания противников — [`enemy-spells.md`](enemy-spells.md).

Метки: **[A]** проверено по заголовкам/логом, **[B]** документация, **[C]** решение дизайна.

| Решение | Где записано |

| Обездвиживание на 10 с — плохой дизайн | все «клетки» и «удержания» выброшены |

## 2. Шесть рычагов, без которых бой = «зажать кнопку»

| Рычаг | Что он делает с игроком | Чем закрыт сейчас |
|---|---|---|
| Таймер | «успей» | стаггер, `chip`, зомби-мина (0,8 с) |
| Движение | сойти с места | столб огня, костяное поле, сковывающая земля, корни |
| Ресурс | отнять магию/выносливость | вытягивание, вампиризм, разрыв магии |
| Приоритет цели | заставить переключиться | подъём зомби, разрыв, кольцо мёртвых |
| Потеря контроля ≤0,8 с | наказать за ошибку | корни, костяное поле |
| Цена атаки | наказать за спам | цепная молния (щит не спасает), отражающая печать |

До 22.11.2026 у нас работал только первый рычаг — отсюда и ощущение «кто кого перетанкует».

## 3. Чужой набор заклинаний: что не берём и почему

Аудит всех 404 записей Apocalypse (что делает каждое заклинание) —
[`reference/apocalypse-spells.md`](reference/apocalypse-spells.md). Итог по твоим критериям:

| Заклинание | Почему не годится |
|---|---|
| Fracture | «не попадай под мороз» — второго решения нет, игрок и не собирался под него попадать |
| Corpse Explosion | труп взрывается «сам», связи с действиями игрока нет — нечитаемо |
| Slay Living | добивание по порогу здоровья — не решение, а лотерея |
| Magicka Void | процент здоровья = процент магии: воина убивает, мага обнуляет |
| Welling Blood | «60 % за 8 с — смерть» = ваншот по факту |
| Malviser's Gauntlet | 10 секунд беспомощности — то, что игроки ненавидят |
| Talons of Nirn, Thrumming Stone | цепочки стаггеров чужого мода непредсказуемы |
| Crackle, Hailstone, Bolide, Sleet Storm, Volcano, Apocalypse | тот же снаряд с другими цифрами — «+5 % урона» |
| Wild Healing, Resurgence, Infinite Light | чистое лечение: бой длиннее, решений нет |
| Entomb, Banish Living | убирают игрока из боя — это не сложный бой, а его отсутствие |

Вывод: **магия врагов — только своя**, 13 заклинаний в [`enemy-spells.md`](enemy-spells.md),
каждое с телеграфом, двумя ответами и потолком урона.

## 5. Порядок работ (не перескакивать)

1. Ты подтверждаешь таблицы матрицы и набор заклинаний — это документы, правятся бесплатно.
2. Правка кода №1: `hit.projectile = any/none` (магия-снаряд против AoE) — маленькая, проверяется логом.
3. Правка кода №2: три заклинания из 13 (по одному на класс), чтобы проверить ощущение телеграфа
   и потолка урона в одном бою.
4. Только потом остальные заклинания и травмы частей тела.

Про Fall of Avalon: я не знаю его боёвку наизусть, поэтому сформулировал требование проверяемым
правилом — «нет нового решения → заклинание не берём». Если назовёшь конкретные приёмы, которые
там нравятся, сведу их в таблицу и буду подгонять под них.
