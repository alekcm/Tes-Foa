# Как проверить правило в бою

**Принцип:** любой враг подходит, искать и спавнить никого не нужно — правила срабатывают на того, кто
уже стоит перед тобой. Результат теста — **строка в логе**, а не ощущение.

Лог: `Документы\My Games\Skyrim Special Edition\SKSE\TGCombatPort.log`.

## Что должно быть в логе при загрузке

```
TGCombatPort vX-Y-Z                                        ← версия, которая реально загрузилась
Rules.txt [...]: правил 8, строк с ошибками 0
настройки: effects=on
  [twohand-warhammer-breaks-shield-block] trigger=hit ... attacker.weapon=warhammer ...
```

Если `строк с ошибками` больше нуля — правило с ошибкой отключено, и в списке ниже у него будет
пометка `(ОТКЛЮЧЕНО: ошибка в файле)`.

## Тесты блока и пробития

| ID | Что делать | Ожидаемо | Строка лога |
|---|---|---|---|
| BL-01 | Поднять блок **оружием** (меч, топор, булава), дать врагу со щитом ударить и башнуть 3 раза | блок держится, стаггера нет | `[shield-bash-staggers-unblocked]` **отсутствует** |
| BL-02 | Опустить блок, получить баш | стаггер ~1 с | `rule fired: [shield-bash-staggers-unblocked]` |
| BL-03 | Враг с **булавой** бьёт силовой по поднятому **щиту** | блок слетает, стаггер | `rule fired: [onehand-mace-power-breaks-shield-block]` |
| BL-04 | Враг с булавой бьёт силовой по блоку **оружием** | блок держится | правила BL-03 нет в логе |
| BL-05 | Враг с **двуручным молотом** бьёт силовой по **щиту** | блок слетает | `rule fired: [twohand-warhammer-breaks-shield-block]` + `hit: оружие … кейворды: … WeapTypeWarhammer` |
| BL-06 | Враг с **двуручным топором** бьёт силовой по **щиту** | блок держится | правила BL-05 нет в логе |
| BL-07 | Враг бьёт **кинжалом** по блоку оружием | блок держится, но HP падает | `chip: 10.0 hp сквозь блок` |
| BL-08 | Враг-**лучник** стреляет по блоку оружием | блок держится, HP падает | `chip: 8.0 hp сквозь блок` |

## Как быстро дать врагу нужное оружие (консоль)

Консоль ставит игру на паузу — бой не убежит.

1. `~` — открыть консоль.
2. `help warhammer` (или `help battleaxe`) — найти строку, где в конце `WEAP`, записать FormID (8 знаков).
3. Кликнуть **по врагу** — вверху консоли появится его имя, значит выбран он, а не игрок.
4. `additem <ID> 1`, затем `equipitem <ID> right`.
5. `~` — закрыть, дать ему замахнуться силовой.

Если оружие не сменилось — повторить `equipitem <ID> 1` без `right`.
Где взять FormID других врагов — [`docs/console_spawn.md`](docs/console_spawn.md).

## Если игра падает в бою

1. Первым делом — **последняя строка лога**. С версии 0.15.0 каждая строка пишется на диск сразу,
   поэтому в файле остаётся место падения: `отправляю staggerStart`, `отправляю blockStop`,
   `отправляю каст`, `chip: наношу` или последняя строка `hit:`.
2. Включить режим без действий: в `Rules.txt` поставить `effects = off` (секция `[settings]`) и
   повторить бой. Плагин в этом режиме только пишет `would fire: …` и **не делает ни одного вызова
   движка**. Если падает и так — причина не в эффектах правил.
3. Модуль падения из Windows: в PowerShell
   `Get-WinEvent -FilterHashtable @{LogName='Application'; ProviderName='Application Error'} -MaxEvents 1 | Format-List TimeCreated,Message`
   — строка `Faulting module name` показывает, чей код упал (`TGCombatPort.dll` или `SkyrimSE.exe`).

## Что означает провал

Если ожидаемой строки нет — сначала смотреть, была ли строка `hit:` вообще. Её отсутствие значит, что
плагин не получил попадание (не тот триггер, враг не бьёт, правило отключено из-за ошибки в файле), а не
«эффект не сработал». Провал не лечится подкруткой чисел: сначала выясняется причина по логу.
