# TGCombatPort — боёвка Skyrim SE: блок, пробития, стаггер

**Что это.** SKSE-плагин (`TGCombatPort.dll`) + файл правил `Rules.txt`, которые вместе меняют
физику боя: что пробивает блок оружием, что пробивает щит, когда срабатывает стаггер, как устроены
пробития уколом, стрелами и магией. Механика задаётся **данными** (`Rules.txt`), код только исполняет
её и пишет лог.

**Состояние (честно).** Последняя версия, проверенная пользователем в игре, — **0.9.0**.
Позже наблюдались вылеты, по последнему сообщению — при загрузке мира. Точная версия и причина
неизвестны; изменения ниже пока не проверены в игре.

## Экспериментальная исправленная сборка 0.16.0

Исправлена преждевременная загрузка форм: правила и подписка теперь инициализируются после
`SKSE DataLoaded`. При переходе между сохранениями временные задачи отменяются; исправлены
время жизни ссылок на актёров и отказ от немедленного выполнения эффекта при отсутствии очереди.
Это исправления выявленных рисков, **не доказательство причины вылета**: нет crash log и нет
проверки в игре. Последняя подтверждённая пользователем сборка остаётся 0.9.0.

Продолжение боевой логики: баш со щитом действует только при настоящем баше по неблокирующему
игроку, а правила стрел/магии не ограничиваются дистанцией баша. Автоматический заказ баша
против блока отключён, потому что противоречил текущему дизайну. Проверка в игре обязательна.

Архив собирается Windows CI; на ветках его можно скачать как артефакт **TGCombatPort-installable**
после успешного запуска Actions. Архив содержит DLL, правила и DAR-анимации, но **не содержит**
ESP и скомпилированные PEX: если они нужны вашему ранее установленному варианту, сохраните их.
Проверяйте в отдельном профиле и не смешивайте файлы разных версий. Инструкция и сбор логов —
[TESTING.md](TESTING.md). Пока нет успешной проверки не публикуйте это как стабильный релиз.

## Сборка и выпуск

```cmd
cd native
xmake f -y -m release
xmake build -y
```

CI (`.github/workflows/native.yml`) на каждый пуш: сверка вызовов движка с заголовками CommonLib,
сборка DLL, упаковка `TGCombatPort-<ref>.zip`, проверка содержимого архива. Тег `vX.Y.Z` публикует
релиз. Подробности — [`BUILD.md`](BUILD.md) и [`RELEASING.md`](RELEASING.md).

## Проверки, которые можно запустить без игры

| Команда | Что проверяет |
|---|---|
| `python -m unittest discover -s tests` | 91 тест инструментов, парсера правил и упаковки |
| `python tools/check_rules.py` | `Rules.txt`: ключи, значения, оружие, эффекты, `[settings]` |
| `python tools/check_docs.py` | ссылки между документами |
| `python tools/verify_audit.py` | каждая функция кода описана, каждая метка `AS-n` есть в реестре |
| `python tools/check_api_usage.py --headers <CommonLib include>` | каждое `RE::Имя` в коде существует в заголовках |

## Железные правила проекта

- **Хуки в код движка не ставим.** В 0.1.1 перехват `Actor::GetAttackChance` (`write_branch`) уронил
  игру при загрузке сейва.
- **Ваншотов нет никогда**: урон за каст ≤ 25 % максимального здоровья, за тик ≤ 9 %.
- **Контроль ≤ 0,8 с**: единственное, что отнимает управление, — стаггер как наказание за ошибку.
- **Заклинание берём, только если оно даёт решение**, которого без него не было.
- **Ничего не выдумывать**: факт без метки `[A]`/`[B]` — гипотеза, её сначала проверяют логом.
